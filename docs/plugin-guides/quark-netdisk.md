# 夸克网盘插件配置指南

夸克网盘插件用于解析 `pan.quark.cn` 的分享链接（转存到自己网盘后取直链下载）。使用前需要在插件设置中填写**夸克网盘 Cookie**。

## Cookie 是什么？为什么需要它？

Cookie 是你登录 pan.quark.cn 后浏览器保存的会话凭据。插件借助它以你的账号身份转存分享文件并获取下载直链。**Cookie 只保存在本机**（应用数据目录的 `plugin_configs.json`），不会上传到任何服务器。

## 获取步骤

1. 在浏览器（推荐 Chrome / Edge）打开 <https://pan.quark.cn> 并登录你的账号。
2. 按 `F12` 打开开发者工具，切换到 **网络（Network）** 标签。
3. 按 `F5` 刷新页面。
4. 点击任意一条发往 `pan.quark.cn` 的请求。
5. 在 **标头（Headers）→ 请求标头（Request Headers）** 中找到 `Cookie` 一项，**复制它的完整值**。
6. 回到 GDownload：插件市场 → 夸克网盘 → 设置，把值粘贴到 "夸克网盘 Cookie" 输入框，点击**保存**。

## 其他设置

- **自动清理转存文件**（默认开启）：取得下载直链后自动删除网盘中的临时转存副本，避免占用你的网盘空间。若想保留转存文件可关闭。

## 常见问题

| 现象 | 原因与处理 |
|------|-----------|
| 解析提示 Cookie 无效 / 需要登录 | Cookie 复制不完整或已过期，重新登录后重新获取 |
| 提示网盘空间不足 | 夸克解析需要先把分享文件转存到你的网盘，请清理网盘空间或开启"自动清理转存文件" |
| 需要验证 | 触发风控时应用会弹出验证界面，按提示完成即可 |

## 安全说明

- Cookie 等同于你的登录凭据，**不要发给任何人**。
- GDownload 仅在本机保存并使用该 Cookie；在插件设置中点击 **Clear** 可随时清除。
