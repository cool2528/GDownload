# 百度网盘插件配置指南

百度网盘插件用于解析 `pan.baidu.com` 的分享链接并添加下载任务。使用前需要在插件设置中填写**百度网盘 Cookie**。

## Cookie 是什么？为什么需要它？

Cookie 是你登录 pan.baidu.com 后浏览器保存的会话凭据。插件借助它以你的账号身份访问百度网盘接口（转存、取直链）。**Cookie 只保存在本机**（应用数据目录的 `plugin_configs.json`），不会上传到任何服务器。

## 获取步骤

1. 在浏览器（推荐 Chrome / Edge）打开 <https://pan.baidu.com> 并登录你的账号。
2. 按 `F12` 打开开发者工具，切换到 **网络（Network）** 标签。
   - Edge 中文界面同为"网络"；Firefox 为"网络监视器"。
3. 按 `F5` 刷新页面，请求列表中会出现大量条目。
4. 点击任意一条发往 `pan.baidu.com` 的请求（例如第一条文档请求）。
5. 在右侧 **标头（Headers）→ 请求标头（Request Headers）** 中找到 `Cookie` 一项，**复制它的完整值**（内容很长，务必从头复制到尾）。
   - 也可以在 Cookie 值上右键 → Copy value。
6. 回到 GDownload：插件市场 → 百度网盘 → 设置，把值粘贴到 "百度网盘 Cookie" 输入框，点击**保存**。

## 常见问题

| 现象 | 原因与处理 |
|------|-----------|
| 解析提示 Cookie 无效 / 需要登录 | Cookie 复制不完整，或网页端已退出登录。重新登录后按上述步骤重新获取 |
| 用了一段时间后失效 | 百度会话有有效期，且网页端退出登录/修改密码会使 Cookie 立即失效。失效后重新获取即可 |
| 需要输入验证码 | 触发了百度风控，应用会弹出验证界面，按提示完成即可 |

## 安全说明

- Cookie 等同于你的登录凭据，**不要发给任何人**，也不要粘贴到不可信的网站或工具。
- GDownload 仅在本机保存并使用该 Cookie；在插件设置中点击 **Clear** 可随时清除。
