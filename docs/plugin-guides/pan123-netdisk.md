# 123 云盘插件配置指南

123 云盘插件用于解析 `123pan.com` 及其系列域名的分享链接。**浏览分享内容无需配置**；下载文件需要在插件设置中填写**登录 Token**。

## Token 是什么？

Token 是你登录 123 云盘网页版后颁发的身份凭据（JWT），插件用它调用下载接口。**Token 只保存在本机**（应用数据目录的 `plugin_configs.json`），不会上传到任何服务器。

## 获取步骤

1. 在浏览器（推荐 Chrome / Edge）打开 <https://www.123pan.com> 并登录你的账号。
2. 按 `F12` 打开开发者工具，切换到 **应用（Application）** 标签。
   - Firefox 对应"存储（Storage）"标签。
3. 左侧展开 **Local Storage（本地存储空间）**，选择 `https://www.123pan.com`。
4. 在右侧列表中找到名为 **`authorToken`** 的条目，点击并**复制它的值**。
   - 找不到时也可以在 **网络（Network）** 标签里任选一条请求，复制请求标头 `Authorization` 的值。
5. 回到 GDownload：插件市场 → 123云盘 → 设置，把值粘贴到 "123云盘登录 Token" 输入框，点击**保存**。
   - 带 `Bearer ` 前缀直接粘贴也可以，插件会自动处理。

## 常见问题

| 现象 | 原因与处理 |
|------|-----------|
| 提示需要登录 token | 未配置 Token 或已过期——浏览免登录，下载必须配置 |
| 下载报错 401 / 鉴权失败 | Token 复制不完整或已失效，重新登录后重新获取 |
| 一段时间后失效 | 123 云盘登录态有有效期，失效后重新获取即可 |

## 安全说明

- Token 等同于你的登录凭据，**不要发给任何人**。
- GDownload 仅在本机保存并使用该值；在插件设置中点击 **Clear** 可随时清除。
